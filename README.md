## เกี่ยวกับโปรเจกต์

โปรเจกต์นี้ใช้สำหรับฝึกเขียน HTML และ Git

เป็นเว็บไซต์สำหรับแนะนำข้อมูลส่วนตัว ทักษะ และความสนใจ
โดยใช้ HTML ในการสร้างโครงสร้างเว็บไซต์
และ CSS ในการตกแต่งหน้าเว็บไซต์ให้สวยงาม
